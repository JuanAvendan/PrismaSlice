Find tickets by what they mean.

Semantic search over a help-desk backlog. Describe the problem in your own words and the API ranks tickets by meaning, not by shared keywords.

Try:

Tickets are synthetic and written in Spanish. Ask in Spanish or English: the model is multilingual.

    How it works

    1. Embed the query. EmbeddingGemma runs inside the .NET API through ONNX Runtime. There is no model server and no external AI API.
    2. Search by meaning. PostgreSQL + pgvector returns the closest tickets by cosine distance, using an HNSW index.
    3. Rank and explain. Each result shows its similarity score. Open a result to see the full ticket.

    ASP.NET Core 10 · EF Core · PostgreSQL + pgvector · ONNX Runtime · Azure Container Apps · Neon · Vercel

    Portfolio project by Juan Avendaño. All data is synthetic. The embedding model is EmbeddingGemma (Gemma Terms of Use).
